# UMABC: Utility-Based Anchor-Shift & Guided Scout ABC

An Enhanced Artificial Bee Colony (ABC) algorithm designed for complex global optimization, specifically evaluated on CEC 2005 and CEC 2013 benchmark suites.

## 📌 Project Overview
This repository contains the official implementation of the **UMABC** algorithm. It introduces advanced strategies to balance exploration and exploitation, including:
* **Utility-Based Anchor-Shift:** Improved local search around high-utility food sources.
* **Guided Scout Strategy:** Enhanced global search to prevent premature convergence.
* **HUFS (High Utility Food Sources):** Selection mechanism targeting the top 20% of the population.

> **⚠️ Performance Note for Reviewers:** > This repository contains an optimized version of the UMABC algorithm. Minor refinements in parameter tuning and the Anchor-Shift logic implemented after the initial manuscript submission have resulted in improved convergence rates and lower error values compared to the results reported in the original paper. This version represents the current State-of-the-Art for the UMABC framework.
